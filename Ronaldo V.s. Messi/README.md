# Notes - Messi vs. Ronaldo World Cup Challenge

## 7 Data Files

- `players.csv` — Individual biological and identity details (Contains data from all historical World Cups)
- `player_appearances.csv` — Match-by-match playtime tracking records (Contains data from all historical World Cups)
- `goals.csv` — Granular tournament scoring log (Contains data from all historical World Cups)
- `bookings.csv` — Misconduct and penalty card registry (Contains data from all historical World Cups)
- `matches.csv` — Administrative match data and location context (Contains data from all historical World Cups)
- `tournament_stages.csv` — Structural tournament map and progression matrix (Contains data from all historical World Cups)
- `cleaned_goat_world_cup_data.csv` — Finished target output dataset (Contains specifically only Messi and Ronaldo data)
